🎯 Trap System Visual Guide

A comprehensive guide to surviving the deadly traps of the dungeon

📋 Overview

Traps are hidden dangers in the dungeon that remain invisible until:

  • You successfully detect them (based on INT and LUCK)
  • You accidentally trigger them (ouch!)

🎲 Detection Mechanics

Detection Chance Formula:
min(95, max(1, 5 + intBonus + luckBonus + (100 - trapDifficulty) / 2))

Where:
• Base Chance = 5%
• INT Bonus = floor((Intelligence - 50) / 10) [+1% per 10 INT above 50]
• Luck Bonus = floor((Luck - 50) / 20) [+1% per 20 LUCK above 50]
• Trap Difficulty = 35 to 70 (trap-specific)
Example: Average Character (INT 50, LUCK 50)
Base: 5%
INT Bonus: 0% (50 is baseline)
Luck Bonus: 0% (50 is baseline)
vs Spike Trap (difficulty 40): 5 + 0 + 0 + (100-40)/2 = 35% chance
vs Teleport Trap (difficulty 70): 5 + 0 + 0 + (100-70)/2 = 20% chance
Example: Smart Character (INT 80, LUCK 70)
Base: 5%
INT Bonus: 3% (floor((80-50)/10) = 3)
Luck Bonus: 1% (floor((70-50)/20) = 1)
vs Spike Trap (difficulty 40): 5 + 3 + 1 + (100-40)/2 = 39% chance
vs Teleport Trap (difficulty 70): 5 + 3 + 1 + (100-70)/2 = 24% chance

⚠️ Key Mechanics

🏃 Running Behavior:
• Running is FAST but RISKY
• You check for traps on EVERY step while running
• Running STOPS immediately if you discover a trap
• Running STOPS if you trigger a trap
• Use shift + arrow keys to run
👁️ Discovered Traps:
• Remain visible on the map permanently
• Cannot be triggered once discovered
• Shown with ^ symbol in color-coded format
• Can be examined with 'x' key for details
💥 Triggered Traps:
• Execute their effect immediately
• Become visible after triggering
• Are single-use (disappear after trigger)
• Generate a message in the log

💡 Strategic Tips

✓ DO:
• Invest in Intelligence for safer exploration
• Walk carefully in new areas (don't run blind)
• Use examine mode ('x') to check suspicious tiles
• Build INT/LUCK for trap-heavy builds
• Remember trap locations on the map
✗ DON'T:
• Run through unexplored areas blindly
• Ignore Intelligence as a "useless" stat
• Assume all floors are safe
• Sprint at low health (one trap = death)
• Forget that deeper levels have deadlier traps
